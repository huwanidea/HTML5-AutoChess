# 西游记自走棋 · HTML5 Auto Chess

> 虚拟现实技术专业毕业设计。基于 HTML5 Canvas 2D + 原生 JavaScript 实现的单机自走棋游戏，无框架、无后端、无构建。

**在线试玩**：<https://huwanidea.github.io/HTML5-AutoChess/>

## 玩法概览

把自走棋的核心循环完整实现了一遍：商店购买 → 备战布阵 → 选秀补强 → 自动战斗 → 回合结算。

```text
初始化资源 → 备战阶段 → 选秀阶段 → 战斗阶段 → 结算阶段 → 下一回合
```

战斗阶段由系统自动完成：索敌、移动、普攻、技能释放、受击、死亡动画，直到分出胜负。玩家血量归零则游戏结束。

## 系统规模

| 项目 | 数量 / 说明 |
| --- | --- |
| 棋盘 | 9 列 × 8 行 = 72 个逻辑格，上半敌方、下半我方 |
| 英雄 | 24 名西游记角色，按 1–5 费分布 |
| 羁绊 | 大唐、花果山、天庭、西天、妖族、龙族共 6 大阵营 |
| 精灵图 | 每个角色一套 5×5 PNG 动画帧 |
| 动画状态 | 待机、移动、攻击 / 技能、受击、死亡 |
| 计划类型 | 单人工作 / 协同工作 / 拓展工作 / 加班工作（对应绩效核算设计） |

## 技术要点

- **精灵图动画**：每个角色一张 5×5 的帧图集，按状态切换帧区间，实现待机呼吸、移动、攻击、受击、死亡的完整动作链。
- **Canvas 渲染**：棋盘、单位、特效全部走Canvas 绘制，UI 层用静态整页壳图+ HTML 动态内容覆盖的混合方案。
- **索敌与战斗逻辑**：自动寻敌、移动寻路、普攻冷却、技能释放判定、伤害结算与死亡回收。
- **性能优化**：做过资源加载兜底（资源缺失时降级不崩）、渲染瘦身与移动端触屏适配。

## 运行方式

推荐用本地静态服务器，Canvas 的像素读取在 `file://` 协议下会被浏览器限制。

```bash
python -m http.server 8010 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:8010/index.html>。

也可以直接部署到任意静态托管（仓库已开启 GitHub Pages）。

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 点击商店卡片 | 购买英雄 |
| 拖拽备战席→ 棋盘 | 上阵英雄 |
| 拖拽棋盘内英雄 | 调整站位 |
| 右键英雄 | 出售英雄 |
| 悬停英雄 | 查看属性面板 |
| 悬停羁绊 | 查看羁绊说明与相关英雄 |

顶部工具栏提供图鉴、跳过、速度、音效、设置、全屏等控制。
